# 도메인 판정 계약

브리프가 정한 목표를 검증 가능한 규칙과 예시로 구체화한다. 미확인 규칙을 AI의 추측으로 확정하지 않는다. 실제 규칙은 사용자 또는 지정한 업무 담당자가 확인한다.

## 용어와 근거

| 용어 / 규칙 ID   | 뜻 / 불변조건                                                                                                              | 출처와 버전                      | 확인자      | 상태      |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------- | ----------- | --------- |
| DOMAIN-HWP-001   | HWP 바이너리 스트림과 HWPX XML 패키지는 파일 헤더 시그니처를 검사하여 올바른 파서로 라우팅해야 한다.                       | edwardkim/rhwp MIT               | 사용자 확인 | confirmed |
| DOMAIN-XLSX-001  | .xlsx 파일 수정 시 수정되지 않은 셀, 스타일, 매크로 XML 파트는 바이트 보존(byte-preserving)으로 원본을 유지해야 한다.      | genspark-ai/genoffice Apache 2.0 | 사용자 확인 | confirmed |
| DOMAIN-CACHE-001 | 사용자가 문서를 편집하는 중 비정상 종료가 발생해도 직전 10초 이내의 수정 내용은 SQLite `session_drafts`에 보존되어야 한다. | ADR-0002                         | 사용자 확인 | confirmed |
| DOMAIN-PERF-001  | 콜드 스타트 기동 시간은 1.5초 이내여야 하며 유휴 메모리 사용량은 100MB를 초과하지 않아야 한다.                             | 프로젝트 브리프                  | 사용자 확인 | confirmed |

## 판정과 변경

- unknown인 핵심 규칙에 의존하는 작업만 보류하고 독립 작업은 계속한다.
- 테스트가 통과해도 업무 기대값의 타당성이 확인된 것은 아니다.
- 기대값 변경은 변경 이유, 확인자, 영향 사례를 기록한다.
- 실제 결함이 발견되면 재현 예시와 검사 경로를 남긴다.
- 민감한 원본 대신 합성 또는 비식별화한 기준 데이터를 사용한다.
