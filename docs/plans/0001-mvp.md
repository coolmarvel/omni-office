# 0001: omni-office MVP 계획

## 개요

한글(HWP/HWPX)과 엑셀(XLSX)을 모두 다루는 초경량 데스크톱 오피스 omni-office의 MVP 마일스톤 계획이다.

## 마일스톤 로드맵

### Milestone 1: 앱 쉘 및 하네스 기반 구축 (즉시 사용 가능)

- [x] Rust + Tauri 2.x 백엔드 및 React + TS 프론트엔드 프로젝트 스캐폴딩
- [x] Fluent UI 기반 메인 윈도우 레이아웃 (리본 툴바, 탭 바, 문서 영역, 상태 표시줄)
- [x] 로컬 SQLite 데이터베이스 초기화 (최근 문서 이력 테이블, 세션 캐시 테이블)
- [x] Rust IPC 파일 열기 및 저장 다이얼로그 연동
- [x] 검증 루프 (cargo check, cargo test, npm run lint, npm run build) 통과

### Milestone 2: HWP / HWPX 뷰어 및 에디터 연동 (rhwp)

- [ ] `edwardkim/rhwp` 모듈 바인딩 (WASM/Rust 파서 연동)
- [ ] HWP 바이너리 및 HWPX XML 구조 파싱 파이프라인 연결
- [ ] 본문 문단 및 글자 모양, 표(Table) 렌더링 캔버스 구현
- [ ] 한글 IME 조합 및 텍스트 수정 에디터 조작 지원
- [ ] HWP/HWPX 문서 파일 로드 및 화면 렌더링 검증 테스트

### Milestone 3: 스프레드시트(.xlsx) 뷰어 및 계산 연동 (genoffice)

- [ ] `genspark-ai/genoffice` 스프레드시트 시트 캔버스 컴포넌트 이식
- [ ] .xlsx 압축 해제 및 OOXML 워크시트 셀 데이터 바인딩
- [ ] 다중 시트 탭 전환 및 가상 스크롤 렌더링 최적화
- [ ] 셀 값 직접 편집 및 기본 수식(SUM, AVERAGE 등) 계산 엔진 연결
- [ ] 대용량 엑셀 파일 열람 시 메모리 점유 및 스크롤 반응성 검증

### Milestone 4: 문서 저장, 바이트 보존 및 자동 복구

- [ ] HWP / HWPX 문서 저장 및 로컬 파일 쓰기 IPC 구현
- [ ] .xlsx 바이트 보존(byte-preserving) 방식 저장 로직 연결
- [ ] 비정상 종료 대비 SQLite 자동 임시저장(Autosave Draft) 백그라운드 태스크
- [ ] 앱 재시작 시 비정상 종료 복구 팝업 및 직전 편집 상태 복원 검증

### Milestone 5: 데스크톱 패키징 및 최종 최적화

- [ ] OS별(Linux .deb/.AppImage, Windows .msi, macOS .dmg) 번들러 설정 구체화
- [ ] 기동 시간 1초 이내 및 유휴 메모리 100MB 이하 실측 및 프로파일링
- [ ] 오프라인 독립 실행 무결성 확인 및 릴리스 배포 준비
