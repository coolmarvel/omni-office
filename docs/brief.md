# 프로젝트 브리프: omni-office

## 한 줄 정의

공공, 행정, 기업 실무자를 위해 한글(HWP/HWPX)과 엑셀(XLSX), 워드 문서를 별도의 무거운 상용 프로그램 설치 없이 초고속으로 열람하고 편집할 수 있는 통합 데스크톱 문서 편집기.

## 문제와 사용자

- **문제**: HWP 문서를 보기 위해 전용 한글 뷰어를 띄우고, 엑셀을 위해 무거운 스프레드시트를 별도로 구동해야 함. 상용 오피스 제품군은 초기 로딩이 느리고 수백 MB 이상의 메모리를 상시 점유하여 가벼운 업무에 부담이 큼.
- **사용자 유형**:

| 유형                  | 이 앱에서 하는 일                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------ |
| 행정 및 사무 실무자   | 공문서(HWP/HWPX)를 빠르게 확인하고 오탈자 및 본문/표를 수정한 뒤 즉시 인쇄 또는 저장       |
| 데이터 및 서식 관리자 | 엑셀(.xlsx) 명세서나 보고서를 열어 셀 데이터를 수정하고 기본 수식을 계산 및 검증           |
| 다중 문서 검토자      | 한 프로그램 안에서 HWP와 스프레드시트를 탭으로 오가며 오프라인 환경에서 안전하게 문서 작성 |

## 핵심 시나리오 (v1.0 에 반드시 되어야 하는 것)

1. 사용자는 로컬의 .hwp/.hwpx 파일을 열어 지연 없이 본문과 표를 확인하고, 한글 텍스트 및 서식을 편집하여 원본 또는 새 파일로 저장한다.
2. 사용자는 .xlsx 스프레드시트 파일을 열어 다중 시트를 탐색하고 셀 데이터 및 수식을 수정한 뒤, 파일 손상 없이 바이트 보존 방식으로 저장한다.
3. 사용자는 최근 열람한 파일 목록을 확인하고 앱 비정상 종료 시 SQLite 자동 임시저장 캐시를 통해 작업 내용을 복구한다.
4. 사용자는 Fluent 리본 툴바 인터페이스를 통해 폰트, 정렬, 표 서식 등 표준 오피스 단축키와 기능을 직관적으로 조작한다.

## 제약

- **플랫폼/형태**: 데스크톱 크로스플랫폼(Linux, Windows, macOS), 100% 로컬 오프라인 구동, 외부 네트워크 전송 없음.
- **성능**: 초기 실행 속도 1초 이내, 기본 유휴 메모리 100MB 이하, 초경량 구동.
- **비용**: 100% 오픈소스(MIT, Apache 2.0) 컴포넌트 활용, 라이선스 준수, 외부 유료 API 비용 없음.
- **라이선스/저작권**: 원작자(이성현) 저작권 표기 및 오픈소스 라이브러리(rhwp, genoffice) 라이선스 고지.

## 성공 기준

- HWP/HWPX 문서와 XLSX 문서를 별도 외부 프로그램 없이 하나의 데스크톱 앱에서 바로 열고, 텍스트 및 셀 값을 수정한 후 저장했을 때 무결성이 유지되는 v1.0.
